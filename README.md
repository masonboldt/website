# Mason Boldt, Freelance Copywriter

Personal website for Mason Boldt's freelance copywriting business. It's a single static page (`index.html`) with all styles included, so there's nothing to install or build.

## Preview locally

Open `index.html` in any web browser.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose the `main` branch and the `/ (root)` folder, then click **Save**.
5. After a minute or two, the site will be live at `https://<your-username>.github.io/<repository-name>/`.

## Editing

All text and styles live in `index.html`. Edit it in a plain-text code editor such as VS Code, not a word processor, which can rewrite the code.

- Colors are defined as variables in the `:root` block near the top of the file. The dark-mode versions are in the two blocks that follow it.
- Fonts (Knewave and Raleway) load from Google Fonts via the `<link>` tag in the `<head>`.
